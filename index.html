How launching works

The full Ammora lifecycle, exactly as implemented by this launchpad with the official SDK examples.

1

Create a Config

Choose fee recipients and the Creator / Partner split, preview the distribution, then create one reusable launchpad Config. npm run launch:team-config

2

Issue the token

The creator launches a new token through Ammora contracts under that Config, with its own pre-graduation bonding curve (ALC). npm run launch:create-launch

3

Trade the curve

Anyone can buy and sell on the curve before graduation, with quotes straight from the SDK. npm run launch:quote → npm run quickstart:swap

4

Graduate & claim fees

When the curve completes, the token graduates to a concentrated ARL pool. Creator and Partner then claim their FeeVault fees. npm run launch:graduate · npm run launch:claim-fees

Launch your own token

Permissionless by design

Creating a valid Config and using the supported WETH launch flow needs no per-team approval from Ammora. Your own wallet signs, sets allowances and pays gas on GIWA Sepolia.

What you need

  • A wallet on GIWA Sepolia (chain 91342) with testnet gas
  • The public examples repo: AmmoraLabs/ammora-examples
  • Node 24 and the pinned SDK: npm install @ammora-protocol/sdk@0.3.9

Fee sharing built in

Every Config carries its own Creator / Partner fee split, before and after graduation. Fees accrue in the FeeVault and are claimed per wallet — this page's config table shows the live owners and fee claimers on chain.
